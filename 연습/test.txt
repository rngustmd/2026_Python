로지스틱 회귀
- 선형식 결과를 0~1 확률로 바꿔 범주를 예측하는 지도학습 분류 알고리즘

시그모이드 vs 소프트맥스
시그모이드
- 실수 값을 0 ~ 1 확률로 압축하는 S자 함수로 , 0.5 기준으로 이진 분류
소프트맥스
- 다중 분류에서 클래스별 점수를 합이 1인 확률 분포로 바꾸는 함수

혼동 행렬
예측 값과 실제 값을 TPTNFPFN 으로 나눈 2차원 표, 오류 유형 진단

정밀도 vs 재현율
정확도   : 맞게 분류한 비율, (TP+TN) / 전체
정밀도   : 양성이라고 예측한 것 중 양성 비율 , TP/(TP+FP)
재현율   : 실제 양성 중 찾아낸 비율 , TP/(TP+FN)
F1 점수  : 정밀도와 재현율의 조화 평균, 불균형 데이터 평가에 사용

결정 트리 : 스케일링이 필요 없고, 예/아니오 질문을 반복하여 데이터를 나누는 지도학습 알고리즘

지니 불순도 : 한 노드에 클래스가 섞여 있는 정도, 0에 가까울수록 순수

정보 이득 : 분할 전 불순도에서 분할 후 불순도를 뺀 값 , 클수록 좋은 분할
가지치기 : 트리 깊이나 리프 최소 샘플 수를 제한해 과적합을 막는 방법
앙상블 : 여러 모델을 조합하여 단일 모델보다 높은 성능과 안정성을 얻는 기법
배깅 vs 부스팅
배깅 : 부트스트랩 샘플로 병렬 학습 후 투표나 평균으로 결합하는 방식
부스팅 : 이전 모델의 오답을 다음 모델이 순차적으로 보완하는 방식
랜덤프레스트 : 부트스트랩 샘플링과 무작위 특성 선택으로 만든 여러 결정 트리의 배깅 앙상블
부트스트랩 : 중복 허용, 무작위로 복원 추출하는 샘플링 방법

결정 트리 vs 랜덤 포레스트
결정 트리는 트리 1개라 과적합되기 쉽고, 랜덤 포레스트는 여러 트리라 안정적임
GBM : 잔차를 다음 트리가 순차적으로 학습, 경사하강법으로 오차를 줄이는 부스팅 알고리즘
경사하강법 : 손실 함수의 기울기를 따라 가중치를 조금씩 수정해 최솟값을 찾는 최적화 방법
XGBoost : 레벨 단위로 트리를 균형 있게 확장하고 L1L2 규제가 내장된 부스팅 모델
LightGBM : 리프 중심으로 확장해 가장 빠른 부스팅 모델
CatBoost : 대칭 트리 구조, 범주형 데이터에 특화된 부스팅 모델

LogisticRegression
시그모이드 소프트맥스로 확률을 계산해 분류하는 로지스틱 회귀 모델 클래스가
DecisionTreeClassifier
불순도 기준으로 데이터를 분할하는 결정 트리 분류 모델
RandomForestClassifier
여러 결정 트리를 배깅으로 묶은 랜덤 포레스트 분류 모델
